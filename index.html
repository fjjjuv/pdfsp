PDFSP v1.0

PDF Scene Patch

PDFSP defines a portable, verifiable JSON format for describing mutations of a PDF document's scene graph. A patch describes what to change, not how to change it: it can be applied by any conforming engine, replayed on related documents, rebased onto newer revisions, and inverted for rollback.

Key properties

  • Semantic selectors instead of coordinates (page[2], table[0].row[1].cell[0], text:'invoice #42')
  • Contracts (only_touch) and post-conditions (verify) built into the format
  • Typed issues — engines never fail silently
  • Sequential, deterministic op application with best-effort or atomic modes
  • Canonical inverses for every op class — rollback without snapshots
