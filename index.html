PDFSP
PDF Scene Patch

Portable, verifiable JSON format for mutating a PDF scene graph — the PDF equivalent of JSON Patch (RFC 6902).

Why it exists

PDFSP defines a portable, verifiable JSON format for describing mutations of a PDF document's scene graph. A patch describes what to change, not how to change it: it can be applied by any conforming engine, replayed on related documents, rebased onto newer revisions, and inverted for rollback.

Key properties

Semantic selectors

Address elements by page[2], table[0].row[1].cell[0], section['Résumé'].para[1] or text:'invoice #42' — not fragile coordinates.

Contracts

only_touch scopes exactly which ids a patch may mutate; violations abort or report contract_violation.

Post-conditions

verify.expect / verify.absent run after application — the engine reports checks, not vibes.

Atomic or best-effort

meta.atomic: true gives all-or-nothing application; default mode reports every issue and continues.

Inversion

Every op class has a canonical inverse — rollback without snapshots.

Typed issues

bad_op, target_not_found, stale_target, contract_violation… never a silent failure.
